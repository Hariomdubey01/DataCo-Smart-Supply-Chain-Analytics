# Dataset

The original DataCo Smart Supply Chain dataset is not included in this repository because the raw CSV file exceeds GitHub's standard file-size limit.

### Dataset Details

- Records: 180,519 order line items
- Columns: 53
- Date Coverage: 2015 – January 2018
- Geographic Coverage: 164 countries
- Distinct Orders: 65,752
- Distinct Products: 118

### Source

The dataset is publicly available through Kaggle:

[DataCo Smart Supply Chain Dataset](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)

Download the dataset and place `DataCoSupplyChainDataset.csv` inside this `Dataset/` folder before running the Python notebook or importing the data into MySQL.
